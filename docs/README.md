# TaxGuard architecture index

For AI agent development, start with [Canonical A00-A60 architecture and authority mapping](taxguard-ai-canonical-architecture.md), then the current gate report and [legacy compatibility mapping](taxguard-ai-legacy-mapping.md).

The canonical registry is src/ai/registry.ts. Runtime mapping metadata is src/ai/architectureMapping.ts. Neither registry metadata nor a completed infrastructure gate activates an agent. Production registrations remain DRAFT and missing authority remains denied.

See [autonomous development checkpoint](taxguard-autonomous-development-checkpoint.md) for validated work, restrictions and the next gate.
